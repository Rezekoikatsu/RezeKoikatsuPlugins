# Studio Character Tools (F6)

[繁體中文](README.md) ・ [English](README.en.md) ・ **日本語**

> 🤖 **Created by Claude AI** —— 本プロジェクトのコードとドキュメントは Claude（Anthropic の AI）が書きました。Reze は発案・指示・ゲーム内での動作確認を担当しています。

CharaStudio 用のシーンキャラ総合管理。**F6** で「シーンキャラ選択」パネルが開き、
シーン上のキャラが 1 人 1 行で並びます。キャラ差し替え、着替え、アクセサリ管理、
ブレンドシェイプ固定、コライダー修復、サムネ撮影とカード保存がすべてここで完結します。

## 前提条件

**必須**のものだけを挙げます。KKAPI、More Accessories、ABMX など、ほぼ誰もが導入済みの一般的なプラグインは省略しています。

| 必須 | 理由 |
|---|---|
| [BepInEx 5](https://github.com/BepInEx/BepInEx) | プラグイン基盤。コイカツの統合パックには同梱 |
| （なし） | F6 に必須の前提はありません。ABMX、KKPE、MaterialEditor が無い場合、その機能が使えないだけです |

## メインパネル

シーン内のキャラを女性・男性の 2 列に分けて表示します。各行には：

| 要素 | 役割 |
|---|---|
| チェック | ワークスペースの目のチェックと同じ。キャラの表示／非表示 |
| キャラ名 | クリックするとそのキャラの操作列を開きます：入れ替え、服装そのまま入れ替え、アクセ追加、ポーズリセット、キャラカード／コーデカード／全コーデ／ポーズ保存、アクセ枠 |
| 選択 | このキャラを左のワークスペースで選択 |
| 着替え | コーデカードを選び、続けて髪などのアクセを戻すか尋ねます |
| コライダー | 「コライダー設定の修復」サイドパネルを開く |
| ブレンドシェイプ | 「ブレンドシェイプ固定」サイドパネルを開く |

各列の一番上にはまとめ操作もあります：全員入れ替え、全員・服装そのまま入れ替え、全員のカード保存。

### 入れ替え時の 4 つの体型モード

入れ替えで一番面倒なのは「顔だけ替えて体型はそのまま」といった要望です。そのため「入れ替え」を押すと、まず体型の扱いを選びます：

1. **通常入れ替え** — 新しいカードをそのまま使う
2. **旧カードの体型** — 新しいカードにするが、体型と ABMX は元のキャラのまま
3. **身長固定** — 身長だけ元に固定し、他は新しいカード
4. **新カードの体型** — 新しいカードの体型を使いつつ、関節位置を決める ABMX ボーン（手足の長さ、身長スケールなど）は残し、
   組んだポーズがずれないようにする

**服装そのまま入れ替え** も同じ 4 モードで、入れ替え後に元の服を着せ直します（別のコーデカードから髪アクセを持ってくることも可能）。

入れ替え時にキャラ名の維持、ポーズの再適用、コライダー設定の復元、同名ブレンドシェイプ設定の適用を自動で行えます（設定で個別にオンオフ）。
「新カードの体型で残す ABMX ボーン」のルールは設定で変更できます。カンマ区切りのワイルドカードで、先頭の `-` は除外です。
ルール外のボーン（顔・胸）は消さずに新カード自身の ABMX を使います。

入れ替え時は既定でシーンの表情（眉・目・口、開き具合、まばたき、頬染め、涙、視線）を維持します。
新しいカードに保存された表情を使いたい場合は、設定の「入れ替え時に表情を維持」をオフにしてください。

### 入れ替え時にシーンのシェーダーを引き継ぐ（MaterialEditor が必要）

シーンカードのライトやポストエフェクトは、たいてい元のキャラのシェーダー（例：xukmi 一式）に合わせて調整されています。
別のシェーダーを使うキャラカードに入れ替えると、色や陰影がシーンと合わなくなります。

設定の「**入れ替え時にシーンのキャラのシェーダーを適用**」は 3 段階です：

| 選択肢 | 動作 |
|---|---|
| オフ | 何もしません。新しいキャラは自分のカードのシェーダーのまま |
| 確認（既定） | カードを選んだあと、入れ替える前に確認：シェーダーを適用／適用しない／入れ替えをキャンセル |
| 自動 | 毎回そのまま適用 |

変更するのは**シェーダーだけ**です。体・顔・白目・瞳・眉・歯・舌・アイライン・鼻線・涙の各パーツで、
マテリアル 0 のシェーダーをシーンの元キャラが同じパーツで使っていたものに替えます。
パラメータ、色、テクスチャ、反射はすべて新しいキャラのまま。マテリアル名ではなく「パーツ（レンダラー）」で対応付けるので、
頭モデルが違っても合います。MaterialEditor が無い場合、この機能は何もしません。

## サイドパネル

- **アクセサリ管理** — キャラの全アクセサリを一覧し、個別に表示切替、他キャラへのコピー。一番上の行で「全部／メイン／サブ」のアクセを一括で表示・非表示・削除できます（削除は 3 秒以内にもう一度押して確定）
- **ブレンドシェイプ固定** — 指定したブレンドシェイプを固定し、差し替えや着替えで上書きされないようにします。モードは固定・範囲・倍率の 3 種類（倍率は表情が書き込んだ値に掛け算するので、顔 MOD の表情キーが強すぎる／弱すぎるときに調整できます。ページ全体に一括適用も可）。「KKPE で調整済みのみ」は KKPE のブレンドシェイプ編集で紫色になっているキーだけを表示します。一番下の「診断」で現在のシェイプキーをテキストファイルに書き出せます（このキャラ／全キャラ）
- **コライダー修復** — 差し替え後に DynamicBone のコライダーが旧キャラに結合されたままになる問題をワンクリックで再結合
- **設定** — 全オプションと一括処理

### アクセサリのグループ拡縮／移動

髪をいくつものアクセで組んだキャラは、1 つずつ拡縮を調整するのが大変です。アクセサリ管理の「**グループ拡縮**」で、チェックしたアクセをまとめて調整できます：

- 一覧でまとめて調整するアクセにチェック。「このグループを選択」「頭・髪を選択」で一括チェックも可能
- **中心**：「各自の親」（既定。各アクセが自分の親を中心に拡縮）または「頭ボーン」（頭を中心にグループ全体を拡縮し、互いの位置関係も一緒に拡縮）
- **拡縮**：X / Y / Z のスライダーを個別に調整。「等比」で 3 軸まとめて動かします。「拡縮リセット」で 100% に戻します
- **位置**：X / Y / Z のスライダー。中心が頭ボーンのときは左右／上下／前後。「位置リセット」で 0 に戻します
- スライダーを動かすとその場でプレビュー。「**確定**」を押すまで書き込まれません。確定後はスライダーが戻るので、続けて調整できます。「キャンセル」で今回の調整を破棄
- 「**直前の確定を戻す**」で最後に確定した調整を元に戻します
- 「**前回の値を適用**」で前回確定した値をスライダーに戻します（保存するにはもう一度確定）。複数のキャラを同じ大きさにしたいときに便利です

### 同期する衣装

アクセサリ管理の一番上にある「**同期する衣装**」には、キャラの各コーデ（学生服（校内）、学生服（下校）、体操着、水着、部活、私服、パジャマ）が並びます。
クリックして赤字にすると選択され、以後いまのコーデで行う**削除・拡縮・移動**が、選択した衣装にも同期されます。

- 「同じ枠・同じアイテム」のときだけ同期します。別のコーデでたまたま同じ枠にある別のアクセを変えてしまうことはありません
- 同期できない衣装（その枠が空、または別のものが入っている）があると、操作後に一番下へ「同期できなかった衣装：…」と表示します

## サムネイルとカード保存

パネルから直接キャラカード・コーデカード・ポーズとして保存できます。サムネイルはその場で撮影します：

- **全コーデ保存** — このキャラの全コーデをそれぞれコーデカードとして保存し、最後に元のコーデに戻します
- 撮影前に物理（髪や胸の DynamicBone）が落ち着くのを待ちます。秒数は調整可能
- そのキャラだけを表示（他は一時的に非表示）、男性キャラも一緒に隠すことも可能
- 構図は「頭を中心」にでき、頭を画面の高さのどこに置くか、画面全体を頭〜足の距離の何倍にするかを指定できます
- サムネイル高さの上限 0 = 縮小しない

設定を決めておけば、まとめて撮ったキャラの構図が揃います。

## 一括処理

設定にはシーン内の**全キャラ**に同じ処理をするボタンがあります：

- 全員のポーズをリセット（「入れ替え後にキャラが伸びる」の修正）
- コライダー設定を一括修復
- アクセを一括追加（同じコーデカードを全員に適用）

## カード合成（kkbridge が必要）

付属の外部ツール **kkbridge** を使って、コーデカードのアクセサリをキャラカードへ合成します。

- `kkbridge.exe` は `StudioCharTools.zip` に同梱しています。ゲームのルートで解凍すると、`BepInEx` と同じ階層に置かれます
- 合成機能を使う前に `kkbridge.exe` を起動し、「ジョブ監視」タブで監視を開始してください。起動していないと合成はタイムアウトしますが、他の機能には影響しません
- ジョブフォルダの既定は `UserData\chara\female\Temp` です。両方とも既定のままなら設定不要。変える場合は F6 の設定と kkbridge で同じフォルダを指定してください
- kkbridge をゲームのルートに置いておけば、ゲームの場所を自動で認識して監視を始めます（設定不要）。別の場所に置く場合は、kkbridge の「設定」タブでゲームのルートを一度指定してください
- ソースは本リポジトリの [`kkbridge/`](../kkbridge/) にあります

## 設定

パネル右下の「設定」から。ウィンドウの最下部に **Language** と
**初期設定に戻す** があります。BepInEx の ConfigurationManager や
`BepInEx\config\reze.studio.chartools.cfg` の直接編集でも構いません。

## 既知の制限

- 「新カードの体型」は ABMX のボーン名をルールと照合して動きます。特殊なボーンを使うカードではルール調整が必要な場合があります。
- シェーダーの引き継ぎはシェーダー本体だけを替えます。新しいカードに元のシェーダー向けの値（xukmi 専用パラメータなど）がある場合は、入れ替え後に微調整が必要かもしれません。
- カード合成は外部 exe に依存します。本プラグインは呼び出しと入出力の受け渡しのみを担当します。
