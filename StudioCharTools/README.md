# Studio Character Tools (F6)

[繁體中文](README.md) ・ [English](README.en.md) ・ [日本語](README.ja.md)

CharaStudio 的場景角色總管。按 **F6** 開啟「選擇場景角色」面板，場上每個角色一列，
換人、換裝、管飾品、鎖形態鍵、修碰撞器、拍縮圖存卡，全部在同一個地方。

## 前置需求

只列**必裝**的。KKAPI、More Accessories、ABMX 這類幾乎人人都有的一般外掛不另外列。

| 必裝 | 說明 |
|---|---|
| [BepInEx 5](https://github.com/BepInEx/BepInEx) | 外掛框架。Koikatsu 的整合包都內建 |
| （無） | F6 沒有非裝不可的前置。ABMX、KKPE、MaterialEditor 這些沒有的話只是少對應的功能 |

## 主面板

面板把場上的角色分成女角色 / 男角色兩欄，每一列有：

| 元件 | 作用 |
|---|---|
| 打勾框 | 等同工作面板那個眼睛勾選，控制角色顯示／隱藏 |
| 角色名稱 | 點下去展開這個角色的操作列：換人、保持服裝換人、添加飾品、重置姿勢、存人物卡／服裝卡／全部換裝／姿勢、飾品欄 |
| 選取 | 把這個角色選到左邊的工作面板 |
| 換衣服 | 開服裝卡選擇，選完接著問要不要帶回頭髮等飾品 |
| 碰撞器 | 開「碰撞器綁定修復」側欄 |
| 型態鍵 | 開「型態鍵鎖定」側欄 |

每一欄的最上面還有整組操作：整組換人、整組保持服裝換人、整組存卡。

### 換人的四種身材模式

換人最麻煩的是「我只想換臉，不想動身材」這類需求。所以按「換人」之後要先選身材怎麼處理：

1. **一般替換** — 整張卡照搬
2. **保留舊卡身材** — 換成新卡，但體型、ABMX 全部維持原本的角色
3. **鎖身高** — 只把身高鎖回原本的，其他照新卡
4. **維持新卡身材** — 用新卡的身材，但留下決定關節位置的 ABMX 骨頭（手腳長度、身高縮放等），
   原本擺好的姿勢才不會錯位

**保持服裝換人** 用同樣四種模式，換完再把原本的衣服穿回去（可以順便帶入另一張服裝卡的頭髮飾品）。

換人時可以自動：保留角色名稱、重新套用姿勢、還原碰撞器綁定、帶入同名的型態鍵預設（都在設置裡開關）。
「維持新卡身材要留的 ABMX 骨頭」那條規則可以在設置裡改，語法是逗號分隔的萬用字元，`-` 開頭表示排除。
規則外的骨頭（臉、胸）會用新卡自己的 ABMX，不會被清空。

換人時預設會保留場景裡的表情（眉／眼／嘴、開合、眨眼、臉紅、眼淚、視線）。
想改用新卡自己存的表情，到設置把「換角色保留表情」改成否。

### 換人時帶入場景的著色器（需要 MaterialEditor）

場景卡的燈光和後製通常是配合原角色的著色器調的（例如整套 xukmi）。換上用別套著色器的人物卡，
顏色和陰影就會跟場景不搭。

設置裡的「**換角色套用場景原角色的著色器**」有三段：

| 選項 | 行為 |
|---|---|
| 關 | 不動，新角色用自己卡上的著色器 |
| 詢問（預設） | 選好人物卡後、真的換人之前先問：套用著色器／不套用／取消換人 |
| 自動 | 每次換人都直接套用 |

只換**著色器**：身體、臉、眼白、眼睛、眉毛、牙齒、舌頭、眼線、鼻線、眼淚這些部位第 0 個材質的著色器，
換成場景原角色同一部位用的那個。參數、顏色、貼圖、反射全部維持新角色自己的。
用「部位」對應而不是材質名稱，所以頭模不同也對得上。沒裝 MaterialEditor 時這個功能安靜地不做事。

## 側欄功能

- **飾品欄管理** — 列出角色身上所有飾品，可以逐一開關、複製到其他角色。最上面一排可以對「全部／主要／次要」飾品一次顯示、隱藏或移除（移除要在 3 秒內再按一次確認）
- **型態鍵鎖定** — 鎖住指定的 blendshape，換人或換裝時不會被蓋掉。三種模式：固定、範圍、比例（表情寫多少就乘上倍率，用來把臉型 mod 偏強或偏弱的表情鍵拉回來，可以整頁一次套用）。「只顯示 KKPE 調過的」只列出 KKPE 形態鍵編輯器裡標成紫色的鍵。最下面的「診斷」可以把目前的形態鍵倒成文字檔（這個角色／全部角色）
- **碰撞器綁定修復** — 換人之後 DynamicBone 的碰撞器常常綁到舊角色身上，這裡一鍵重綁
- **設置** — 所有設定和一鍵批次操作

### 飾品整組縮放／移動

頭髮用好幾個飾品拼出來的角色，一個一個調縮放很累。飾品欄裡的「**整組縮放**」可以一次調整勾選的所有飾品：

- 在清單裡勾選要一起調的飾品，或用「勾選本類」「勾選頭部類」一次勾
- **中心**：「各自掛點」（預設，每個飾品以自己的掛點縮放）或「頭部骨頭」（以頭為中心，整組一起放大縮小，彼此的相對位置跟著縮）
- **縮放**：X / Y / Z 三條滑桿分開調，按「等比」三軸一起動；「縮放歸位」回到 100%
- **位置**：X / Y / Z 三條滑桿，中心是頭部骨頭時是左右／上下／前後；「位置歸位」回到 0
- 拖滑桿就會即時預覽。按「**確定**」才真的寫進去，之後滑桿歸位，可以再接著調；「取消」放棄這次的調整
- 「**復原上一次確定**」把最後一次確定的調整退回去
- 「**套用上次值**」把上一次確定的數值套回滑桿（一樣要再按確定才存），適合好幾個角色要調成一樣大小

### 同步服裝槽

飾品欄最上面的「**同步服裝槽**」列出角色的每一套換裝（學生服（校內）、學生服（放學）、體操服、泳裝、社團、私服、睡衣）。
點成紅字就是選中，之後在目前這套做的**刪除、縮放、移動**，都會同步到選中的服裝槽。

- 只有「同一格、同一個飾品」才會同步，避免改到別套剛好放在同一格的不同飾品
- 有沒辦法同步的服裝槽（那一格是空的或放的是別的東西），操作完會在最下面顯示「有無法同步之服裝槽：…」

## 縮圖與存卡

面板上可以直接把角色存成人物卡、服裝卡或姿勢，縮圖是當場拍的：

- **存全部換裝** — 一次把這個角色的每一套換裝各存成一張服裝卡，存完切回原本那套
- 拍之前會等物理安定（頭髮、胸部的 DynamicBone 晃完），秒數可調
- 可以只顯示該角色（其他人暫時隱藏）、可以連男角色一起隱藏
- 取景可以「以頭部為中心」，並指定頭要落在畫面高度的幾成、整個畫面等於頭腳距離的幾倍
- 縮圖高度上限 0 = 不縮放

這幾個參數配好之後，整批角色拍出來的構圖會一致。

## 一鍵批次

設置裡有幾個對場上**所有**角色做同一件事的按鈕：

- 一鍵重置所有姿勢（修「換完人物被拉伸」）
- 一鍵修復碰撞器綁定
- 一鍵添加飾品（同一張服裝卡套到所有角色）

## 合卡（需要 kkbridge）

把服裝卡的飾品合併進人物卡，靠配套的外部工具 **kkbridge** 完成。

- `kkbridge.exe` 已經包在 `StudioCharTools.zip` 裡，在遊戲根目錄解壓縮後就在根目錄（跟 `BepInEx` 同一層）
- 用合卡功能前先把 `kkbridge.exe` 開著，在「監看工單」分頁開始監看；它沒開的話合卡會逾時，其他功能不受影響
- 工單資料夾預設是 `UserData\chara\female\Temp`，兩邊都用預設就不用設定；要改的話 F6 的設置和 kkbridge 要指到同一個資料夾
- kkbridge 會自己找常見的安裝位置（`C:`～`F:` 的 `\Koikatu`）；遊戲裝在別的地方的話，第一次開啟時到它的「設定」分頁填一次遊戲根目錄
- 原始碼在這個 repo 的 [`kkbridge/`](../kkbridge/)

## 設定

面板右下的「設置」開啟，最底下有 **Language** 和 **重置為預設**。
也可以用 BepInEx 設定管理器，或直接改 `BepInEx\config\reze.studio.chartools.cfg`。

## 已知限制

- 「維持新卡身材」靠的是 ABMX 骨頭名稱的規則比對。用了非常規骨頭的卡片可能要自己調規則。
- 帶入著色器只換著色器本身。新卡如果有針對原本著色器調的參數（例如 xukmi 專用的數值），換過去之後可能要自己再微調。
- 合卡需要外部 exe，本外掛只負責叫它、整理輸入輸出。
