# Studio CutScene (F7)

[繁體中文](README.md) ・ [English](README.en.md) ・ **日本語**

> 🤖 **Created by Claude AI** —— 本プロジェクトのコードとドキュメントは Claude（Anthropic の AI）が書きました。Reze は発案・指示・ゲーム内での動作確認を担当しています。

過場ムービーとボイスを **Timeline** に同期して再生します。**F7** でパネルが開きます。

シーンカード 1 枚につき `.cutscene.json` を 1 つ用意し、タイムラインの何秒でどの動画を
再生するか、どの区間にどの音声を当てるかを記述します。シーンカードを読み込むと、
同名の設定ファイルが自動的に適用されます。

> **Timeline プラグイン（Joan6694 版）が必要です。** 本プラグインは Timeline を前提に
> 作られており、無い場合はほぼ機能しません。

## Koikatsu Sunshine

1.15.0 から Koikatsu Sunshine 版があります。`StudioCutScene_KKS.zip` をダウンロードし、Sunshine のゲームルートで解凍してください（こちらも Timeline が必要です）。設定ファイルの形式はコイカツ版と同じなので共用できます。現時点の制限：

- VR 視点とコントローラー操作には F9 が必要ですが、F9 の Sunshine 版はまだ無いため、Sunshine では動作しません
- 結合カードの各シーンの空・シェーダータイプ（Sunshine だけにあるシーン設定）は切り替わらず、カード自体の設定がそのまま使われます
- コイカツで作った結合カードを Sunshine で再生する場合：標準マップと時間帯の番号が 2 つのゲームで異なるため、マップや時間帯が合わないことがあります。この環境に無いマップはスキップされます
- 2 つのゲームの DLL に互換性はありません

## 前提条件

**必須**のものだけを挙げます。KKAPI、More Accessories、ABMX など、ほぼ誰もが導入済みの一般的なプラグインは省略しています。

| 必須 | 理由 |
|---|---|
| [BepInEx 5](https://github.com/BepInEx/BepInEx) | プラグイン基盤。コイカツの統合パックには同梱 |
| **Timeline**（Joan6694） | 本プラグインは Timeline を前提に作られており、無い場合ほぼ機能しません。HF Patch に同梱、または [Joan6694 の Patreon](https://www.patreon.com/joan6694) |

## 設定ファイル

**ファイル名はシーンカードと同名にしてください**：`MyScene.png` → `MyScene.cutscene.json`。次の 2 か所を探します：

1. **シーンカードと同じフォルダ**
2. `UserData\cutscene\`（フォルダは設定で変更可、セミコロン区切りで複数指定、サブフォルダも再帰的に探索）

カードは識別できたが同名の設定ファイルが無い場合、パネルは空のままになり、付けるべきファイル名を表示します。
カードがまったく識別できない場合だけ、タイムラインの総再生時間で照合します。パネルの「今すぐ再検索」で探し直せます。

設定ファイルは **[kkscenebridge](../kkscenebridge/README.ja.md)** の「ムービー音声」タブで生成できます。
下記の形式で手書きすることもできます。

### だいたいこんな形

```jsonc
{
  "videoFile": "UserData/cutscene/source.mp4",   // 共通のソース動画
  "tracks": [                                     // 音声トラック = シーン区間
    { "from": 0.0,   "to": 235.0,  "audio": "@", "offset": 0 },
    { "from": 235.0, "to": 509.01, "audio": "@", "offset": 0 }
  ],
  "cuts": [                                       // 過場
    { "t": 0.0,    "kind": "opening",    "videoStart": 0,  "videoEnd": 8 },
    { "t": 235.01, "kind": "transition", "videoStart": 8,  "videoEnd": 14 }
  ]
}
```

- `tracks` の各要素がパネルの「シーン N 開始」ボタンになります
- `cuts` の `kind` は `opening` / `transition` / `ending`
- `audio` が `"@"` なら現在選択中のボイス版、`"@名前"` で版を指定、それ以外はパスとして扱われます
- トラックには対応点として `anchorT` / `anchorA` の並行配列を持たせられます。シーンに
  タイムスケールのトラックがある場合は**必須**で、無いと誤差が累積していきます
- `//` と `/* */` のコメント、末尾のカンマを許容します（手で編集する前提のため）

`example.cutscene.json` がそのまま編集できるテンプレートです。

**ボイスのバージョン**：`variants` に各ボイス（日本語版・中国語版など）を並べ、パネルで即座に切り替えられます。
編集が違うバージョン（オープニングがない等）は、`variantMaps` に「メインボイスの秒数 → このバージョンの秒数」を記録し、
切り替え時に自動で換算します。メインボイスと同じ長さのバージョンには不要です。

**複数のカードを 1 枚につなげた場合**（1.14.0 以降。kkscenebridge の「シーン結合」が書き出す設定がこれです）：各カードの音声と動画は
結合せず、再生している区間に合わせてプラグインがファイルを切り替えます。

- トラックごとに音声ファイルを持てます：`"files": { "ボイス名": "この区間の音声ファイル", … }` と、この区間専用の `"maps"`
  （`variantMaps` と同じ形式で、秒数はそのファイルのもの）。指定があれば `"@"` はここから探し、パネルのボイスボタンもそのまま切り替えられます
- 次の区間が別の音声ファイルのときは、境目の少し前にバックグラウンドで読み込むので、無音の隙間ができません
- ムービーごとに元動画を持てます：`"source": "動画のパス"`（`videoStart` / `videoEnd` と併用。ファイル全体を再生する `video` とは別物）と、
  `"track": トラック番号` —— ムービー中にどのトラックの音声を流し続けるか
- トラックに `"cardStart": true` を付けられます（1.15.2 以降）：この区間が次の元カードの先頭であることを示します。
  シークバーのチャプターマークの色が変わるだけです（下の「パネル」参照）
- これらの項目がない設定の動作は今までと全く同じです

kkscenebridge は json に `pairs`（各区間の先頭と末尾の対応点）も書き込みます。万一ある区間の
`anchors` が空配列になった場合（生成側で曲線が解けないと起こります）、プラグインは `pairs` から
先頭と末尾を補って直線で内挿し、パネルにオレンジ色で警告します。この仕組みが無いと、その区間は
音声ファイルの 0 秒から再生されてしまいます —— 前後の区間は正常で中央だけがずれるため、
原因の特定が非常に困難です。

## パネル

- 再生／一時停止／停止／最初から（オープニング込み）、ドラッグできるシークバー
- シークバーの ▼▲ はチャプター（各「シーン N 開始」の位置）です：**青**は同じカード内のシーン、**赤**は元カード同士のつなぎ目
  （kkscenebridge 1.1.7 以降が複数カードの設定をつなげるときに付けます。古い結合設定はもう一度つなげると付きます）
- **区間リスト** — 各過場を `test` で単独試聴、スキップ、リセットできます。「シーン N 開始」を
  押すとその区間から再生し、その区間自身の過場は**再生しません**
- **すべての過場をスキップ** — 今回だけの設定で、設定ファイルには書き込みません
- **自動リプレイ** — タイムラインが最後まで行って 0 に戻ったとき再生し直すか（既定はオフ。
  オンにすると延々ループします）
- **ショートカット** — 再生・一時停止・停止・リプレイ・前後のシーン・早送り・巻き戻し・スキップにデスクトップのショートカットを設定できます
- **クイック試聴** — 動画と音声のパスを貼るだけで設定ファイルを触らずに確認できます
- **VR 視点** — 下記参照
- **詳細設定** — カクつき補償、色空間、診断。既定では非表示で、cfg の
  「Show Advanced Section」で出せます

## マップと画面効果の切り替え

kkscenebridge で結合したカードで、シーンごとに内蔵マップや画面効果が違う場合、各シーンに
`[MAPINFO]` / `[ENV]` マーカーフォルダがあります。F7 は再生中のシーンに合わせてマップ（MOD マップ含む）と画面効果を自動で切り替えます：

- **マーカーフォルダ（またはその親）をオフにするとそのシーンのマップがオフ**。マーカーフォルダを動かすとマップも動きます
- Studio で手動でマップを変更／削除した場合、そのシーンでは自動で戻しません（次のシーンかカード再読み込みで再適用）
- F7 がなくてもカードは再生できますが、全シーンで同じマップになります

## VR 視点（F9 が必要）

Studio VR Tools を入れていると、シーン区間ごとにヘッドセットの視点を保存できます：

- VR 内でトリガー＋X により視点を記憶し、同時にカードの隣の `<カード名>.view.json` に書き込みます
- 再生中に次の区間へ入ると、自動的にその視点へ移動します
- 音声トラックが無いカードは全体で 1 区間として扱われ、視点は 1 つです

パネルにも「保存／削除／適用」のボタンがあるので、ヘッドセット無しでも操作できます。

## コントローラーでの再生操作（F9 が必要）

VR 中に**グリップ＋トリガー**を押している間、その手が本プラグインのリモコンになります：

| 操作 | 動作 |
|---|---|
| Y | 一時停止／再生（過場の再生中はその過場をスキップ） |
| スティック右／左 | 1 秒 早送り／巻き戻し。押しっぱなしで連続 |
| スティック上を 1 秒 | 最初から再生 |
| スティック下を 1 秒 | 停止 |

## トラブルシューティング

**再生ボタンが効かない** — ログの `[CutScene] Timeline 掃描：` の行で、選ばれた型が
`Timeline.Timeline` になっているか確認してください。名前に「Timeline」を含むプラグインが
複数読み込まれていると誤選択が起こり得ます。本プラグインは候補をスコア付けして選び、
シークに失敗した際は自動で再スキャンします。

**違う区間が再生される** — たいていは設定ファイルの対応ミスです。シーンカードと
同名になっているか確認してください。

**カクついた後に音がずれる** — 詳細設定の「タイムライン最大フレーム時間」で Timeline に
停止時間をそのまま認識させられますが、そのフレームで大量の FixedUpdate が走るため、
重いシーンではかえって悪化します。既定では変更しません。

## 設定

パネル最下部の **UI スケール**（60%〜200%）、**Language**、**初期設定に戻す**、あるいは
`BepInEx\config\reze.studio.cutscene.cfg` を直接編集してください。
