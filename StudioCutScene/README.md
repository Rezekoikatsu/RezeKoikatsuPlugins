# Studio CutScene (F7)

**繁體中文** ・ [English](README.en.md) ・ [日本語](README.ja.md)

> 🤖 **Created by Claude AI** —— 這個專案的程式碼與說明文件都是由 Claude（Anthropic 的 AI）寫的；Reze 負責發想、提需求、在遊戲裡實測。

讓過場影片和配音跟著 **Timeline** 走。按 **F7** 開面板。

做法是每張場景卡配一份 `.cutscene.json`，裡面寫好「時間軸第幾秒要播哪支影片」
和「哪一段時間配哪個音檔」。載入場景卡時會自動找同名的設定檔套上。

> **需要 Timeline 外掛**（Joan6694 的那支）。這支插件整個是圍著 Timeline 做的，
> 沒有它幾乎沒有功能。

## 設定檔

**檔名必須和場景卡同名**：`我的場景.png` → `我的場景.cutscene.json`。會在這兩個地方找：

1. **場景卡旁邊**（同一個資料夾）
2. `UserData\cutscene\`（資料夾可在設定裡改，分號隔開可以多個，會遞迴往下找）

認得出是哪張卡卻沒有同名設定檔時，面板會維持空白並告訴你該取什麼檔名。
完全認不出是哪張卡時，才退回用「時間軸總長度」比對。面板上的「立刻重找」會重新搜尋一次。

設定檔可以用 **[kkscenebridge](../kkscenebridge/README.md)** 的「添加動畫音頻」分頁產生，
也可以照下面的格式手寫。

### 大致長這樣

```jsonc
{
  "videoFile": "UserData/cutscene/source.mp4",   // 共用來源影片
  "tracks": [                                     // 音軌 = 場景段落
    { "from": 0.0,   "to": 235.0,  "audio": "@", "offset": 0 },
    { "from": 235.0, "to": 509.01, "audio": "@", "offset": 0 }
  ],
  "cuts": [                                       // 過場
    { "t": 0.0,    "kind": "opening",    "videoStart": 0,  "videoEnd": 8 },
    { "t": 235.01, "kind": "transition", "videoStart": 8,  "videoEnd": 14 }
  ]
}
```

- `tracks` 每一段對應面板上的「場景 N 開始」按鈕
- `cuts` 的 `kind` 可以是 `opening` / `transition` / `ending`
- `audio` 填 `"@"` 表示用目前選的配音版本，`"@名稱"` 指定版本，其他當成路徑
- 音軌可以用 `anchorT` / `anchorA` 兩個平行陣列做對應點，場景有「時間流速」軌道時必須用它，
  否則誤差會一路累積
- 支援 `//` 和 `/* */` 註解、結尾多餘逗號（手改設定檔很需要）

`example.cutscene.json` 是一份可以直接改的範本。

**配音版本**：`variants` 列出各版配音（例如日配、中配），面板上可以即時切換。
各版剪輯不一樣時（某一版少了開場），`variantMaps` 記錄「主配音的第幾秒 → 這一版的第幾秒」，切換時自動換算。
跟主配音同長度的版本不需要對照表。

kkscenebridge 會在 json 裡一併寫入 `pairs`（每一段的頭尾對應點）。萬一某一段的 `anchors`
變成空陣列（產生端算不出曲線時會發生），插件會自動從 `pairs` 把頭尾補回來、
拉一條直線，並在面板上用橘字警告。沒有這一層的話，那一段會從音檔 0 秒開始播 ——
前後段都正常，只有中間對不上，非常難查。

## 面板

- 播放 / 暫停 / 停止 / 從頭播（含開場），以及可拖曳的進度條
- **段落清單** — 每一段過場可以單獨 `test` 試播、`跳過`、或重設；每個「場景 N 開始」按下去會從那一段開始播，而且**不會**重播那一段自己的過場
- **跳過所有動畫** — 這一次不看過場，不會寫進設定檔
- **自動重播** — 時間軸播到底繞回 0 時要不要再播一次（預設關，否則整部會無限循環）
- **快捷鍵** — 播放、暫停、停止、重播、上／下一個場景、快進、倒轉、跳過動畫都可以設桌面快捷鍵
- **快速試播** — 貼一個影片和音訊路徑直接看，不用改設定檔
- **VR 視角** — 見下
- **設定區** — 卡頓補償、色彩空間、診斷。預設整區隱藏，要用的話在 cfg 裡把「Show Advanced Section」打開

## 地圖與畫面效果切換

用 kkscenebridge 合併的卡，如果各段用的內建地圖或畫面效果不一樣，每段會有一個
`[MAPINFO]` / `[ENV]` 記號資料夾。F7 會照目前播到的段落自動切換地圖（包含模組地圖）和畫面效果：

- **取消勾選記號資料夾（或它的上層）＝關掉那段的地圖**；搬動記號資料夾＝搬動地圖
- 在 Studio 裡手動換掉／刪掉地圖的話，這一段不會再自動切回來（換段或重新載入卡片才會再套用）
- 沒裝 F7 時卡片照樣能播，只是每段都會看到同一張地圖

## VR 視角（需要 F9）

裝了 Studio VR Tools 的話，可以把每一段場景的頭顯視角存起來：

- 在 VR 裡用手柄「扳機＋X」記住視角，會同時寫進卡片旁的 `<卡片檔名>.view.json`
- 播放中跨進下一段時自動把視角移過去
- 沒有音軌的卡片整張算一段，就存一個視角

面板上也有「存目前視角 / 刪除 / 套用」三顆鈕，不進 VR 也能操作。

## 手柄遙控（需要 F9）

在 VR 裡按住**握把＋扳機**，那隻手就變成這支插件的遙控器：

| 操作 | 動作 |
|---|---|
| Y | 暫停／播放（正在播過場時＝跳過這一段） |
| 搖桿右／左 | 快轉／倒轉 1 秒，按著連發 |
| 搖桿上推滿 1 秒 | 重播 |
| 搖桿下推滿 1 秒 | 停止 |

## 疑難排解

**播放鈕按了沒反應** — 看 log 裡 `[CutScene] Timeline 掃描：` 那一行，確認選到的型別是
`Timeline.Timeline`。同時載入多個名字含 Timeline 的外掛時可能認錯，插件會計分挑選並在跳轉
失敗時自動重掃一次。

**過場播錯段落** — 通常是設定檔對到錯的卡。檢查檔名是否和場景卡同名。

**卡頓之後聲音對不上** — 設定區的「時間軸最大幀時距」可以讓 Timeline 認完整的停頓時間，
但代價是那一幀會補跑大量 FixedUpdate，重場景反而更糟。預設不動。
