# Studio VR Tools (F9)

[繁體中文](README.md) ・ [English](README.en.md) ・ **日本語**

> 🤖 **Created by Claude AI** —— 本プロジェクトのコードとドキュメントは Claude（Anthropic の AI）が書きました。Reze は発案・指示・ゲーム内での動作確認を担当しています。

CharaStudio の VR 操作一式。**F9** でパネルが開きます。

> CharaStudio 用 VR プラグイン [Ermin610/KK_VR](https://github.com/Ermin610/KK_VR)（VRGIN 系）が必要です。詳しくは下の「前提条件」を参照。
> **デスクトップモードでは本プラグインは完全に沈黙します** —— VR 機能はすべて自動で
> 無効になり、エラーも出ません。

> [!WARNING]
> **Meta Quest 3 でしか試していません**（SteamVR 経由）。ボタン名（X／Y、グリップ、トリガー、スティック）は Quest コントローラー基準です。
> 他のヘッドセットやコントローラー（Index、Vive、WMR、Pico など）は未検証で、**動作は保証できません** —— ボタンが合わない場合は「コントローラー設定」で割り当て直してみてください。

## 前提条件

**必須**のものだけを挙げます。KKAPI、More Accessories、ABMX など、ほぼ誰もが導入済みの一般的なプラグインは省略しています。

| 必須 | 理由 |
|---|---|
| [BepInEx 5](https://github.com/BepInEx/BepInEx) | プラグイン基盤。コイカツの統合パックには同梱 |
| **[Ermin610/KK_VR](https://github.com/Ermin610/KK_VR)** | CharaStudio の VR 本体（VRGIN 系）。これが無いと F9 の VR 機能はすべて静かに無効化されます |
| **[YukyoMoe/KK_VR_CameraSync](https://github.com/YukyoMoe/KK_VR_CameraSync)** | VR 視点をスタジオカメラに追従させます（Timeline 再生にも対応）。F9 の「カメラ視点に戻る」と過場の整列はこれに依存します。`BepInEx\plugins\KK_VR_CameraSync\` に置きます |
| **SteamVR / OpenVR** | および CharaStudio を `--vr` または `--studiovr` で起動 |

## コントローラー

| 操作 | 動作 |
|---|---|
| スティック | 平行移動 |
| グリップ＋スティック | その場で旋回（支点は目の位置） |
| グリップ＋X／Y | 下降／上昇 |
| トリガー＋スティック | 周回。上下と左右それぞれ軸を選べ、支点は目か原点かを選べます |
| トリガー＋X | 現在の視点を記憶 |
| トリガー＋Y | 記憶した視点に戻る |
| Y（単押し） | メインパネル：元の位置 → 手に固定 → 非表示 → 繰り返し |
| スティック押し込み | カメラ視点に戻る（自分で移動した分を戻す） |
| **グリップ＋トリガー**（押しっぱなし） | 再生操作モード。下記参照 |

左右それぞれの移動速度を個別に設定できます。すべてのキー割り当ては
「コントローラー設定」で変更できます：行の「設定」を押してから、**ヘッドセットで使いたい組み合わせを直接押します**
（グリップ・トリガーは修飾キー、スティックを倒し切るのも可）。全部離すと記録されます。
2 つの操作が同じ組み合わせになると警告が出ます。右上のボタンで旧ドロップダウン方式にも戻せます。

### 再生操作モード（F7 が必要）

グリップ＋トリガーを押している間、その手が Studio CutScene のリモコンになります。
押している間はその手の移動と旋回が停止するので、早送りしながら画面が回ることはありません。

| 操作 | 動作 |
|---|---|
| Y | 一時停止／再生（過場の再生中はその過場をスキップ） |
| スティック右／左 | 1 秒 早送り／巻き戻し。押しっぱなしで連続 |
| スティック上を 1 秒 | 最初から再生 |
| スティック下を 1 秒 | 停止 |

上下だけ「奥まで倒して 1 秒保持」なのは意図的です。最初から再生と停止は現在の
再生状態を破棄するため、誤操作の代価がシークより大きいからです。
1 回のスキップ秒数、連続の速さ、長押し秒数、スティックのしきい値は「コントローラー設定」の「再生操作」で調整でき、
モード自体をオフにすることもできます。

## UI の視認性

IMGUI はヘッドセット内では半透明で、文字がほとんど読めません。ここで対処します：

- **不透明なウィンドウ外観** — GUI スキンを差し替え、トグルは単色＋白枠にしてオンとオフを明確に区別
- **UI に不透明な背景板** — パネルの背後に不透明な板を置きます
- **メインパネルを手に固定** — パネルをコントローラーに貼り付け。距離・縮尺・角度・浮かせ量・表裏反転を調整可能

この設定は F6 と F7 のパネルにも適用されます（3 つのプラグインが外観設定を共有します）。

## VR 時のオブジェクト自動非表示

一部のエフェクトはモニタでは綺麗でも、ヘッドセット内では真っ赤になったりぼやけたりします
（Two Tone Fog や Depth of Field などのポストエフェクトが典型）。この機能は
**VR に入ると自動でチェックを外し**、VR を抜けると元に戻します：

- ID ではなく**名前**で照合します。Sideloader は実行時に mod アイテムの ID を振り直すため、
  シーンカード内の ID と実行中の ID は一致しません。名前は安定しています
- フォルダに対応。シーン合成で生成される `(FX) 1`、`(FX) 2` のような連番も対象です
- **`(FX)` フォルダ**は独立したトグルになっており、「VR 時に非表示にするか」も設定できます
- 「選択中のものをリストに追加」で、いま選んでいるオブジェクトやフォルダをそのまま追加できます
- 機能をオフにすると、この機能が外したチェックだけを戻し、他には触りません

## ヘッドセット内での過場再生（F7 が必要）

F7 が過場ムービーを再生する際、ヘッドセット内にパネルを出して表示します。距離・幅・
頭に追従するかを調整できます。再生中は動画のみを描画してポストエフェクトを切ることもできます
（VR で動画が赤っぽく見えるのはたいていポストエフェクトが原因です）。

## カメラ視点に戻る

VR 内で移動した後、スタジオカメラに紐づいた視点へ戻します。自分が加えた変位をそのまま
打ち消す方式なので、カメラがカメラワーク中でも成立します。KK_VR_CameraSync を入れていれば、
併せて再整列を依頼することもできます（既定でオン）。

## 設定

パネル右下に **コントローラー設定** と **設定** の 2 つのサブウィンドウがあり、
どちらも最下部に **Language** と **初期設定に戻す** があります。「設定」には **UI スケール**（60%〜200%）もあります。
`BepInEx\config\reze.studio.vrtools.cfg` の直接編集でも構いません。

「コントローラー設定」の最下行には、いま押しているボタンがリアルタイムで表示されます。
1 回押せばどの番号を割り当てればよいか分かるので、ログを見るためにヘッドセットを
外す必要はありません。

## トラブルシューティング

**コントローラーが反応しない／レーザーが出ない** — コントローラー設定の最下行を見てください。
「1 本も検出できず」は VRGIN がまだコントローラーを渡していない状態です（シーン読み込み直後の
数秒は正常）。いつまでも出ない場合は、他の何かが SteamVR のデバイス枠を占有している可能性があります。

**デスクトップで `VR Manager has not been created yet!` が大量に出る** — 旧版の不具合です。
VR が無い状態で VRGIN の遅延シングルトンを読んでしまい、VRGIN にオブジェクトを生成させていたのが
原因でした。修正済みです。
