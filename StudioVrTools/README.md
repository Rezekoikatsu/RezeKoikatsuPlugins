# Studio VR Tools (F9)

[繁體中文](README.md) ・ [English](README.en.md) ・ [日本語](README.ja.md)

CharaStudio 在 VR 裡的操作總成。按 **F9** 開面板。

> 需要 VRGIN 系的 VR 外掛（例如 KKCharaStudioVRPlugin）。
> **桌面模式下這支插件完全安靜** —— 所有 VR 功能自動停用，不會有任何錯誤。

## 前置需求

只列**必裝**的。KKAPI、More Accessories、ABMX 這類幾乎人人都有的一般外掛不另外列。

| 必裝 | 說明 |
|---|---|
| [BepInEx 5](https://github.com/BepInEx/BepInEx) | 外掛框架。Koikatsu 的整合包都內建 |
| **[Ermin610/KK_VR](https://github.com/Ermin610/KK_VR)** | CharaStudio 的 VR 本體（VRGIN 系）。沒有它，F9 的 VR 功能全部靜默停用 |
| **[YukyoMoe/KK_VR_CameraSync](https://github.com/YukyoMoe/KK_VR_CameraSync)** | 讓 VR 視角跟著工作室相機走（含 Timeline 播放）。F9 的「回到相機視角」和過場對齊都靠它。放在 `BepInEx\plugins\KK_VR_CameraSync\` |
| **SteamVR / OpenVR** | 以及 CharaStudio 要用 `--vr` 或 `--studiovr` 參數啟動 |

## 手柄操作

| 操作 | 動作 |
|---|---|
| 搖桿 | 平移 |
| 握把＋搖桿 | 原地轉身（支點在眼睛） |
| 握把＋X／Y | 下降／上升 |
| 扳機＋搖桿 | 繞轉，上下和左右各一根可選的軸，支點可選眼睛或原點 |
| 扳機＋X | 記住目前視角 |
| 扳機＋Y | 回到記住的視角 |
| Y（單按） | 主介面：原處 → 黏在手上 → 隱藏 → 循環 |
| 搖桿中鍵 | 回到相機視角（把自己移動出去的量退回去） |
| **握把＋扳機**（按住） | 播放控制模式，見下 |

左右手的移動速度可以分開設定。所有按鍵綁定都可以在「手柄設置」裡改：
按該列的「設定」之後，**直接在頭顯裡按你要的組合**（握把、扳機可以當修飾鍵，搖桿推到底也算），全部放開就記住。
兩個動作綁到同一組時會警告。右上角可以切回舊的下拉式設定法。

### 播放控制模式（需要 F7）

按住握把＋扳機，那隻手整個變成 Studio CutScene 的遙控器。按住期間這隻手的移動和
轉向會停用，免得快轉的同時畫面在轉。

| 操作 | 動作 |
|---|---|
| Y | 暫停／播放（正在播過場時＝跳過這一段） |
| 搖桿右／左 | 快轉／倒轉 1 秒，按著連發 |
| 搖桿上推滿 1 秒 | 重播 |
| 搖桿下推滿 1 秒 | 停止 |

上下要推滿並按住 1 秒是故意的 —— 重播和停止會把目前的播放狀態整個作廢，誤觸代價比快轉大。
快轉一次幾秒、連發速度、要按住幾秒、搖桿門檻都可以在「手柄設置」的「播放控制」裡調，也可以整個關掉。

## 介面清晰度

IMGUI 在頭顯裡預設是半透明的，字幾乎讀不出來。這一區負責把它變清楚：

- **不透明視窗外觀** — 換掉 GUI skin，開關項用實色加白框，關掉的項目有明顯對比
- **介面加不透明黑底** — 在面板後面墊一塊不透明底板
- **主介面黏在手上** — 把面板貼到手柄上，距離、縮放、角度、抬離、正反翻轉都可調

這一區的設定會同時套用到 F6 和 F7 的面板（三支插件共用同一份外觀設定）。

## VR 自動關物件

有些特效物件在桌面上好看，在頭顯裡只會變成一片紅或糊掉（典型是 Two Tone Fog、
Depth of Field 這類後製）。這一區在**進 VR 時自動取消勾選**它們，離開 VR 時再勾回去：

- 依**名稱**比對，不是依 ID —— Sideloader 會在執行期重新編號 mod 物件，場景卡裡的 ID 跟實際跑起來的不一樣，名稱才穩定
- 支援資料夾，也支援 `(FX) 1`、`(FX) 2` 這種合併場景後自動產生的編號
- **`(FX)` 資料夾**另外做成一個獨立開關，並可設定「進 VR 時是否關掉它」
- 「把選取的加入清單」可以直接把你現在選的物件或資料夾加進去
- 關閉這個功能時，原本被它取消勾選的會勾回去，沒動過的不動

## 頭顯裡的過場畫面（需要 F7）

F7 播過場影片時，在頭顯裡擺一塊板子播出來。距離、寬度、是否跟著頭轉都可調。
也可以在播放時只畫影片、關掉後製特效（VR 裡影片泛紅通常就是後製造成的）。

## 回到相機視角

VR 裡自己移動之後要回到「綁在工作室相機上」的視角。做法是把自己移動出去的量原樣退回去，
所以相機正在運鏡中也成立。裝了 KK_VR_CameraSync 的話可以順便叫它重新對齊（預設開）。

## 設定

面板右下有 **手柄設置** 和 **設置** 兩個子視窗，兩個的最下方都有
**Language** 和 **重置為預設**。也可以改 `BepInEx\config\reze.studio.vrtools.cfg`。

「手柄設置」裡最底下那一行會即時顯示你現在按著哪些鍵 —— 綁鍵的時候按一下就知道
該選哪個編號，不用脫下頭顯去翻 log。

## 疑難排解

**手柄沒反應／沒有射線** — 看「手柄設置」最底下那一行。顯示「一支都沒掃到」表示
VRGIN 還沒把手柄交出來（載入場景後幾秒內正常）。如果一直沒有，可能是 SteamVR 的
裝置編號被其他東西佔走了。

**桌面模式跳一堆 `VR Manager has not been created yet!`** — 這是舊版的問題，
起因是在沒有 VR 的情況下讀了 VRGIN 的惰性單例而讓它生出物件。現已修正。
