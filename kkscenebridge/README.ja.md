# kkscenebridge — コイカツ シーンカード結合ツール

[繁體中文](README.md) ・ [English](README.en.md) ・ **日本語**

> 🤖 **Created by Claude AI** —— 本プロジェクトのコードとドキュメントは Claude（Anthropic の AI）が書きました。Reze は発案・指示・ゲーム内での動作確認を担当しています。

CharaStudio のシーンカード複数枚を順番に 1 枚へ結合し、その後のボイス・ムービー・オブジェクト整理まで行います。
Studio で手作業だと一晩かかる作業（カメラ削除、フォルダ分け、Timeline のずらし、カメラの引き継ぎ、VNGE 音声の設定）が、
カードを追加して並べ、ボタンを押すだけになります。

## タブ

| タブ | 内容 |
|---|---|
| **シーン結合** | シーンカードを順番に 1 枚へ結合（1 枚だけなら整理のみ） |
| **ムービー音声** | 結合したカード用に F7（Studio CutScene）の `.cutscene.json` を生成：ムービー、ボイス、対応点 |
| **VNGE 音声** | VNGE の VNSound でシーンごとにボイスを付ける（F7 不要） |
| **整理** | カードのオブジェクトツリーを直接編集：ドラッグ移動、新規フォルダ、名前変更、非表示、削除、位置変更 |
| **設定** | パス、詳細設定、言語 |

## シーン結合

1. シーンカードをリストにドラッグ（または「カードを追加…」）。リストの順番＝再生順
2. 各カードで残すカメラを 1 台選ぶ
3. 「フォルダ名」に共通名を入力して Enter。ラッパーフォルダが `名前_(1)`、`名前_(2)`… になります
4. VNGE 音声を付けるなら「音声を一括割り当て」か各行の「音声を選択…」（不要なら何もしない）
5. 「結合を実行」

ツールが自動で行うこと：

- **各カードの整理**：選んだカメラだけを残して（親フォルダごと）`(CAM)` へ移し、他はすべて `<名前>_(n)` にまとめ、
  空の `(MAP)` `(FX)` `(CHAR)` `(SFX)` フォルダを作成
- **結合**：後ろのカードのオブジェクト番号をまとめてずらし、Timeline を続きの時間へ移動、テクスチャは内容で重複排除
- **プラグインデータも結合して番号を振り直し**：Timeline、NodesConstraints、KKPE、MaterialEditor、
  RendererEditor、OBJImport、TreeNodeNaming、LightSettings、ItemLayerEdit、SaveCameraObjectFOV、
  Sideloader（MOD オブジェクト）、VNGE 音声
- **出番の切り替え**：出番以外のシーンはオブジェクト有効トラックでオフにし、遠くへ退避させることもできます
- **カメラ引き継ぎ**：新しいカメラを作り、境目ごとに次のシーンのカメラへ切り替え。カメラのないカードには初期視点固定のカメラを自動作成できます
- **マップと画面効果**：シーンごとに内蔵マップや画面効果が違う場合、各シーンに `[MAPINFO]` / `[ENV]` マーカーフォルダを置きます。
  F7 を入れていれば再生中に自動で切り替わります。**マーカーフォルダをオフにするとそのシーンのマップがオフ**になります
- 整理済みのカード（ルートに `(CAM)` がある）はそのまま使います

長さの欄は編集できます：延長＝最後のフレームで静止、短縮＝終端を超えるキーフレームを削除。
実際のアニメが宣言された長さより長いカードは、その欄が赤くなり入力すべき値を表示します。

## ムービー音声（F7 の設定ファイル生成）

手順はタブ上部に表示されます：**① シーンを結合 → ② 動画／ボイスを選ぶ → ③ 対応点を測る → ④ 設定を生成**。

- **動画とボイス**：元の動画と各ボイスをリストにドラッグ。チェックした音声がボイスのバージョンになり、
  `★ソース` の動画がムービー映像の元になります
- **対応点**：内蔵プレーヤーで画面を探し「この秒数を取り込む」で動画の秒数を表に入れ、timeline の秒数はゲームの
  Timeline パネルから写します。各シーン最低 2 点
- **cutscene.json を生成**：`UserData\cutscene\<カード名>.cutscene.json` に書き出します（F7 はシーンカードと同じフォルダも探します）

補助機能：

- 動画から wav を抽出、各ボイスの音量を同じラウドネスに揃える（EBU R128）
- ソース動画を無音・キーフレーム密の作業用動画に変換（シークが正確に）
- **カット済み音声から対応点を逆算** — 以前 VNGE で作ったカードは音声がシーンごとにカットされています。元の音声と照合して対応点を自動で測ります
- **ボイス対応** — あるボイスだけ編集が違う（オープニングがない等）場合に換算表を測り、F7 でボイスを切り替えた時にその場で換算します

上記の動画・音声処理には **ffmpeg** が必要です —— `kkscenebridge_ffmpeg.zip` には同梱済み。それ以外は下の [ffmpeg](#ffmpeg) を参照。

## VNGE 音声

結合したカードを読み込んで「自動マッチ」を押すと、ラッパーフォルダ名で音声フォルダから対応する音声を探します
（例：`CharcardPT1` → `_(1)`）。シーンごとに 1 グループを作り、そのシーンの `(SFX)` で再生します。
1 シーンに複数の音声がある場合は 1 つが 100%、他は 0% になり、Studio で即座に切り替えられます。

保存モードはカード全体で共通です：相対パス（既定、音声は音声ルートの下に必要）、絶対パス、カードに埋め込み。

## 整理

- ドラッグ移動、新規フォルダ、名前変更、表示切替、位置／回転／拡縮 — Timeline と NC には影響しません
- **削除**：まず印を付け、保存時に実際に削除し、Timeline・NC などの参照もすべて自動修正
- キャラの接続点の中のものは同じ接続点の中でしか移動できません
- 上書き保存の前に既定で `<カード名>.png.bak` を作成します

## 設定

- **ゲームフォルダ**：他のパス（カード、出力、音声ルート）は既定でここから算出され、変更すると連動します
- **詳細設定**：既定値のままで普通は大丈夫です。各項目にマウスを乗せると説明が出ます
- **Language / 語言 / 言語**：最下部。変更後に再起動してください

設定は exe の横の `kkscenebridge_settings.json` に保存されます。

## ffmpeg

Releases には 2 種類あり、違いは ffmpeg を同梱しているかどうかだけです：

| ダウンロード | 内容 | 向いている人 |
|---|---|---|
| **`kkscenebridge_ffmpeg.zip`** | `kkscenebridge.exe` ＋ `ffmpeg\`（`ffmpeg.exe`・`ffprobe.exe`） | 解凍してすぐ使いたい、ffmpeg を自分で入れたくない |
| **`kkscenebridge.zip`** | `kkscenebridge.exe` のみ | 既に ffmpeg がある、または動画・音声処理を使わない（かなり小さい） |

どちらも解凍すると `kkscenebridge` フォルダが 1 つできます。置き場所は自由です。新しい版が出たときは
`kkscenebridge.exe` だけ差し替え、`ffmpeg` フォルダはそのまま使えます（更新時は小さい `kkscenebridge.zip` で十分です）。

同梱の ffmpeg は無改変のサードパーティ製ビルドで、kkscenebridge 本体の一部ではなく、MIT ライセンスの対象外です。
ライセンス（GPL）とソースへのリンクは `ffmpeg\README_ffmpeg.txt` にあります。別の版を使いたい場合は `ffmpeg` フォルダを差し替えてください。

ffmpeg がなくても、使えなくなるのは「ムービー音声」タブの動画・音声処理だけで、
**シーン結合・VNGE 音声・整理・設定にはまったく影響しません**。

### ffmpeg がないと使えない機能（すべて「ムービー音声」タブ）

| 機能 | ボタン |
|---|---|
| 動画から wav を抽出 | 「チェックした動画から wav を抽出」「wav を抽出（ファイルを選ぶ…）」 |
| 各ボイスの音量合わせ | 「音量を合わせる…」、「抽出後に音量を合わせる」チェック |
| 無音作業動画への変換 | 「★ソースを無音作業動画に変換」「無音に一括変換（ファイルを選ぶ…）」 |
| カット済み音声から対応点を逆算 | 「カット済み音声から逆算…」ウィンドウの「照合開始」 |
| ボイス対応の自動スキャン | 「ボイス対応…」ウィンドウの「必要なバージョンを全部スキャン」「選択中のものだけスキャン」 |

### 一部のチェックが省略される（機能自体は使えます）

- ファイル追加時の「同一編集チェック」（全長の比較）は省略されます
- `cutscene.json` 生成時の動画・ボイスの長さ測定：wav はヘッダーを直接読みます。動画は内蔵プレーヤーで開いている時だけ測れ、
  開いていなければレポートの「エンディングまでカバーしているか」のチェックがなくなります

### ffmpeg がなくても使えるもの

内蔵プレーヤー、手動での対応点取得、`pairs.txt` の読み書き、**`cutscene.json` の生成**。
ボイスを自分で wav にしておけば（他のソフトで動画から変換）、作業の流れはそのまま最後まで進められます。

### ffmpeg を自分で入れる場合（`kkscenebridge.zip` を使う人向け、どちらか）

**方法 A：winget（Windows 10 / 11 標準、いちばん簡単）**

1. スタートメニューで「ターミナル」か「コマンド プロンプト」を検索して開く
2. 次の 1 行を入力して Enter：
   ```
   winget install --id Gyan.FFmpeg -e
   ```
3. 終わったら **kkscenebridge を閉じて開き直す**（新しく PATH に追加されたものは再起動しないと読めません）

**方法 B：手動でダウンロードして kkscenebridge の横に置く（PATH の変更不要）**

1. <https://www.gyan.dev/ffmpeg/builds/> から **`ffmpeg-release-essentials.zip`** をダウンロード
2. 解凍し、出てきたフォルダ（例：`ffmpeg-8.0-essentials_build`）を **`ffmpeg` に名前変更**
3. そのフォルダを `kkscenebridge.exe` の横に置き、`kkscenebridge\ffmpeg\bin\ffmpeg.exe` になるようにする
4. kkscenebridge を開き直す

**確認**：「設定」タブ最下部に `ffmpeg：<パス>` と出れば認識されています。赤字の「見つかりません」なら認識されていません。

> essentials / full などの **GPL 版**を使ってください。LGPL と書かれた版には libx264 がなく、「無音作業動画に変換」が失敗します。

## 必要なもの

- Windows。Releases の zip なら Python のインストールは不要です
- 「ムービー音声」タブの動画・音声処理には [ffmpeg](https://ffmpeg.org/) が必要です：`kkscenebridge_ffmpeg.zip` に同梱、または各自インストール。上の [ffmpeg](#ffmpeg) を参照
- 結合カードのムービーとマップ切替には、ゲーム側に **F7（Studio CutScene）** が必要。VNGE 音声には VNGE が必要

## 注意

- **元のカードは残しておいてください。** ツールは元カードを変更しませんが、結合をやり直す時に必要です
- 大きなカード（1 GB 超）は読み書きに数分かかります。ウィンドウが応答しなくても正常です
- `shaderType` はカード全体で 1 つの値なので、結合では 1 つしか残せません。シーンごとに違う場合はログに `[注意]` が出ます
- 1 枚のカードにしかないプラグインデータは丸ごとコピーされますが、中の番号は振り直されません（ログに一覧が出ます）
- 結合エンジンの技術的なログは中国語のままです。UI と主なメッセージは翻訳されています

## ソースから実行 / パッケージ化

```
run_source.bat          ソースから直接実行（不足パッケージは自動インストール）
build.bat               PyInstaller で dist\kkscenebridge.exe を作成
```

依存パッケージ：`pip install kkloader==0.1.23 msgpack PyQt6 numpy`（パッケージ化には `pyinstaller` も）

コマンドライン（UI なし）：

```
python kkscenemerge.py info  <カード.png>
python kkscenemerge.py prep  <カード.png> --name "シーンA" [--camera <dicKey>] --out <出力.png>
python kkscenemerge.py merge <1枚目> <2枚目> [3枚目 ...] --out <結合.png>
```
